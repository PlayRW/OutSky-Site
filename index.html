HWID — лимит устройств у провайдера

Если провайдер ограничивает число устройств, OutSky сможет передавать ID устройства, который такие провайдеры требуют. Включается отдельно для каждой подписки.

My ProviderЛимит: 3 устройства · используется 2
Отправлять ID устройства
7c1e9a40-2f6b-4d1e-9b83-…

Случайный идентификатор, а не отпечаток железа. Вместе с ним провайдер увидит ОС, её версию и имя устройства (его можно изменить). Выключено по умолчанию, ID можно сбросить в любой момент.

Вопросы

Частые вопросы

OutSky — это VPN-сервис?

Нет. OutSky — клиент: серверов и подписок он не продаёт. Нужна подписка вашего провайдера или собственный сервер.

Где скачать?

Пока нигде — приложение в разработке. Первой выйдет публичная альфа для Windows. Следите за новостями в канале @outskyapp.

Это бесплатно?

Да, OutSky бесплатный. Подписку на серверы вы получаете у своего провайдера.

Нужна регистрация?

Нет. Добавили подписку — и подключились.

Мой провайдер ограничивает число устройств. Подойдёт?

Должен подойти: OutSky сможет передавать ID устройства (HWID), который требуют такие провайдеры. Это случайный идентификатор, а не отпечаток железа; вместе с ним провайдер увидит ОС, её версию и имя устройства. ID включается отдельно для каждой подписки, и его можно сбросить в любой момент.

Собирает ли OutSky данные?

Телеметрии не будет. Логи остаются на устройстве, а при экспорте журнала ключи и пароли скрываются. ID устройства включается только по вашему желанию и отдельно для каждой подписки.

Какие платформы?

Сначала Windows, затем Android и iPhone, позже macOS и Linux. Для браузера уже есть расширение — оно работает с OutSky VPN.
